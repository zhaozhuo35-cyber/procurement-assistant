# 智能研发样件采购助手系统

一个基于 AI 的智能采购助手系统，帮助快速解析采购需求、匹配供应商。

## 特点

- 🤖 AI 智能需求解析
- 🎯 智能供应商匹配
- 📊 数据看板统计
- 📚 历史案例检索
- 🎨 包豪斯设计风格 + 墨绿色主题

## 使用说明

1. 在 Settings 中配置 `AI_API_KEY`（从 [Kimi开放平台](https://platform.moonshot.cn/) 获取）
2. 在"供应商管理"中添加供应商信息
3. 使用"AI需求解析"功能智能匹配供应商

## 技术栈

- Streamlit
- Pandas
- Plotly
- SQLite
